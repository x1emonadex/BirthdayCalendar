# Календарь дней рождения

Приложение-календарь дней рождения: одно и то же приложение для **Android** и
**Windows** из одной кодовой базы на Flutter. Работает полностью офлайн,
данные хранятся в локальной базе на устройстве.

## О проекте

Цель — не потерять дни рождения: приложение собирает их в одном месте,
показывает, что скоро, раскрашивает календарь по месяцам, напоминает
уведомлениями и умеет выгружать список в Excel, CSV и JSON.

Всё считается на устройстве: сеть не нужна ни для работы, ни для напоминаний.
Синхронизации между устройствами нет — перенос делается файлами экспорта и
резервной копии.

## Возможности

Четыре вкладки:

- **Ближайшие** — дни рождения по трём разделам: сегодня, на неделе, позже.
- **Календарь** — месячный и годовой вид, 12 месяцев на одном экране; дни с
  днями рождения отмечены долей заливки по числу праздников. Месяцы листаются
  стрелками и свайпом влево-вправо, годовой вид — так же.
- **Все** — поиск, фильтр «только важные», 4 сортировки, разделители по
  месяцам, свайп-удаление с подтверждением и возможностью вернуть запись.
- **Настройки** — тема и цвет, состав вкладок, напоминания, перенос и копия.

## Функции

- Экспорт в Excel и CSV, импорт с дедупликацией по UUID и по нормированному
  имени с датой, отчёт об ошибках по строкам.
- Резервная копия в JSON: восстановление заменяет список целиком.
- Уведомления с настраиваемыми сроками: кроме «за неделю», «за день» и
  «в день рождения» можно добавить любое число дней; уведомления одного дня
  объединяются в одно. Текст читается фразой — «Сегодня день рождения у 5
  человек», — а не обрывком «Дни рождения: 5».
- Времён напоминания может быть несколько — например, утром и вечером. Каждое
  добавляется кнопкой, у каждого свой выключатель и удаление; выключенное время
  остаётся в списке, но не планируется.
- Расписание пересчитывается фоном (Android, WorkManager, раз в 12 часов):
  после наступления даты напоминания обновляются без запуска приложения.
- Виджет на рабочий стол (Android): до пяти ближайших дат, люди с одним днём
  рождения идут одной строкой. Размер меняется по ширине и высоте. Настройки
  виджета открываются по долгому нажатию: прозрачность подложки, сколько дней
  показывать и нужен ли заголовок.
- Аватары: фотография или цвет у каждого дня рождения.
- Тёмная, светлая и AMOLED-тема, 6 акцентов (фиолетовый, синий, бирюзовый,
  зелёный, оранжевый, розовый) плюс произвольный цвет из палитры.
- Перенос 29 февраля по настройке: на 28 февраля или на 1 марта.
- Перестановка и скрытие вкладок — кроме «Настроек», иначе их не вернуть.

## Скачать

Готовые сборки — в разделе
[**Releases**](https://github.com/x1emonadex/BirthdayCalendar/releases/latest).
Номер версии входит в имя файла:

| Платформа | Файл |
| --- | --- |
| Android | `birthday-calendar-<версия>-android.apk` |
| Windows | `birthday-calendar-<версия>-windows.zip` |

Установка: на Android — открыть APK и разрешить установку из этого источника;
на Windows — распаковать архив и запустить `birthday_calendar.exe`.

## Сборка и запуск

```sh
flutter pub get

# Android
flutter build apk --release

# Windows (нужен Developer Mode для симлинков)
flutter build windows --release
```

Запуск в режиме разработки:

```sh
flutter run
```

Иконка приложения рисуется кодом, а не лежит картинкой. После правки пропорций
или цветов в `tool/app_icon.dart` её нужно пересобрать — команда пишет готовые
PNG прямо в `android/app/src/main/res`:

```sh
flutter test tool/app_icon.dart
```

## Тесты

```sh
flutter test
```

316 тестов в 16 файлах, все проходят. Покрыта чистая логика: расчёт дат
(включая 29 февраля и переход через Новый год), группировка, репозиторий на
реальной базе в памяти, парсер импорта и чтение файла, планировщик
уведомлений, календарь, тема и навигация.

```text
lib/
  app.dart              MaterialApp, статус-бар, AMOLED-тема
  main.dart             инициализация локали, Drift, темы
  core/
    database/           Drift-схема, schemaVersion = 2
    routing/            GoRouter, состав вкладок
    theme/              Material 3, акценты, AMOLED-ступени
    providers/          БД, репозиторий, часы

    calendar/           месячный и годовой виды, маркеры дней
    export_import/      Excel, CSV, импорт с дедупликацией
    notifications/      планировщик (чистая логика) + плагин + фоновая задача
    settings/           настройки, резервные копии
    profiles/           профиль «Мой список»
    widget/             тексты для виджета на рабочем столе
```

## Известные ограничения

- Синхронизации между устройствами нет.
- Без MSIX-упаковки на Windows `cancelAll` и `pending()` не работают: это
  ограничение плагина уведомлений, не ошибка приложения.
- Виджет и фоновый пересчёт расписания есть только на Android.
- Несколько профилей есть в модели и провайдере, но не выведены в интерфейс.

## Заметки по архитектуре

Внутренние решения, причины выбора и список известных грабель описаны в
[`PROJECT.md`](PROJECT.md) — документ для быстрого входа в проект: почему день
