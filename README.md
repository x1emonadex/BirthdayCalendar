# Календарь дней рождения

Приложение-календарь дней рождения: одно и то же приложение для **Android** и
**Windows** из одной кодовой базы на Flutter. Работает полностью офлайн,
данные хранятся в локальной базе на устройстве.

## О проекте

Цель — не потерять дни рождения: приложение собирает их в одном месте,
показывает, что скоро, раскрашивает календарь по месяцам, напоминает
уведомлениями и умеет выгружать список в Excel, CSV и JSON.

Всё считается на устройстве: сеть не нужна ни для работы, ни для напоминаний.
Синхронизации между устройствами нет — перенос делается файлами экспорта и
резервной копии.

## Возможности

Четыре вкладки:

- **Ближайшие** — дни рождения по трём разделам: сегодня, на неделе, позже.
- **Календарь** — месячный и годовой вид, 12 месяцев на одном экране; дни с
  днями рождения отмечены долями круга по числу праздников.
- **Все** — поиск, фильтр «только важные», 4 сортировки, свайп-удаление.
- **Настройки** — тема и цвет, состав вкладок, напоминания, перенос и копия.

## Функции

- Экспорт в Excel и CSV, импорт с дедупликацией по UUID и по нормированному
  имени с датой, отчёт об ошибках по строкам.
- Резервная копия в JSON: восстановление заменяет список целиком.
- Уведомления с настраиваемыми сроками: кроме «за неделю», «за день» и
  «в день рождения» можно добавить любое число дней; уведомления одного дня
  объединяются в одно.
- Аватары: фотография или цвет у каждого дня рождения.
- Тёмная, светлая и AMOLED-тема, 6 акцентов (фиолетовый, синий, бирюзовый,
  зелёный, оранжевый, розовый) плюс произвольный цвет из палитры.
- Перенос 29 февраля по настройке: на 28 февраля или на 1 марта.
- Перестановка и скрытие вкладок — кроме «Настроек», иначе их не вернуть.

## Сборка и запуск

```sh
flutter pub get

# Android
flutter build apk --release

# Windows (нужен Developer Mode для симлинков)
flutter build windows --release
```

Запуск в режиме разработки:

```sh
flutter run
```

## Тесты

```sh
flutter test
```

290 тестов в 12 файлах, все проходят. Покрыта чистая логика: расчёт дат
(включая 29 февраля и переход через Новый год), группировка, репозиторий на
реальной базе в памяти, парсер импорта, планировщик уведомлений, календарь,
тема и навигация.

## Структура репозитория

```text
lib/
  app.dart              MaterialApp, статус-бар, AMOLED-тема
  main.dart             инициализация локали, Drift, темы
  core/
    database/           Drift-схема, schemaVersion = 2
    routing/            GoRouter, состав вкладок
    theme/              Material 3, акценты, AMOLED-ступени
    providers/          БД, репозиторий, часы
    utils/              чистая логика дат, правило 29 февраля
  features/
    birthdays/          модель, репозиторий, CRUD, группировка, сортировки
    calendar/           месячный и годовой виды, маркеры дней
    export_import/      Excel, CSV, импорт с дедупликацией
    notifications/      планировщик (чистая логика) + плагин
    settings/           настройки, резервные копии
    profiles/           профиль «Мой список»
  shared/widgets/       адаптивный каркас навигации
test/                   290 тестов, 12 файлов
windows/, android/      платформенные оболочки
tool/publish_release.ps1  публикация релиза
```

## Известные ограничения

- Синхронизации между устройствами нет.
- Без MSIX-упаковки на Windows `cancelAll` и `pending()` не работают: это
  ограничение плагина уведомлений, не ошибка приложения.
- Несколько профилей есть в модели и провайдере, но не выведены в интерфейс.
- Виджетов на рабочем столе нет.

## Заметки по архитектуре

Внутренние решения, причины выбора и список известных грабель описаны в
