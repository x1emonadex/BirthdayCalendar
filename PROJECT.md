# Календарь дней рождения — описание проекта

Документ для передачи в новый чат. Читай его вместо повторного обхода
кода: здесь то, что не видно из структуры файлов.

## Что это

Календарь дней рождения на Flutter. Одно приложение для Android и
Windows из одной кодовой базы.

Репозиторий: <https://github.com/x1emonadex/BirthdayCalendar>

Релизы: `v1.0.0`, `v1.0.1`, `v1.0.2`, `v1.0.3` (актуальный).

## Где лежит окружение

Рабочая папка переименована из `E:\VSCode` в `E:\BirthdayCalendar`.
Путь зашит в нескольких местах, все исправлены:

| Где | Что |
|---|---|
| `tools/fl.bat`, `tools/emu.bat` | берут корень от расположения скрипта |
| Переменные окружения | 6 штук, все на `E:\BirthdayCalendar\caches\...` |
| `flutter config` | `android-sdk` указывает на новый путь |
| Android Studio | `android.sdk.path.xml`, `trusted-paths.xml` |
| `.vscode/tasks.json` | задача запуска эмулятора |
| AVD `*.ini` | пути к самому AVD, скину и образам дисков |
| `android/local.properties` | пересоздаётся Flutter, в `.gitignore` |

**Developer Mode** нужен для сборки Windows (симлинки). Включается в
Параметры → Для разработчиков. После перезагрузки Windows сбрасывается.

## Что сделано

- **БД**: `Profiles`, `BirthdayEntries` (день и месяц числами, не датой),
  `AppSettings` (пары ключ-значение).
- **Логика дат** — чистые функции: `nextOccurrence`, `ageAt`,
  `celebrationDateInYear`, перенос 29 февраля.
- **Репозиторий**: CRUD, 4 сортировки, поиск в Dart, фильтр «важные».
- **Экраны**: Ближайшие (3 раздела), Календарь (месяц + год), Все
  (поиск, фильтры, свайп-удаление), Настройки.
- **Тема**: светлая, тёмная, AMOLED. 6 акцентов плюс произвольный цвет.
- **Аватары**: фото или цвет. Новая запись сразу получает случайный
  цвет из палитры `AvatarColor`.
- **Уведомления**: сроки настраиваются (любое число дней), время,
  «только важные», пересчёт при запуске.
- **Экспорт/импорт**: `.xlsx` и `.csv`, дедупликация по UUID и по
  нормированному имени с датой, отчёт об ошибках по строкам.
- **Резервные копии**: JSON, восстановление заменяет список целиком.
- **Вкладки**: перестановка, скрытие (кроме «Настроек»).

## Принятые решения

- **День и месяц хранятся числами**, не датой: у дня рождения нет года в
  календарном смысле, так не бывает проблем с часовыми поязами.
- **Год рождения необязателен** — без него возраст не показывается.
- **Расчёты — чистые функции** с аргументом `now`. Тесты детерминированы.
- **Вкладку «Настройки» нельзя скрыть**: иначе её не вернуть, а значит
  и состав вкладок. Проверяется чистой функцией `canHideTab`.
- **Случайный цвет у новой записи**: без него в календаре были мелкие
  точки, которые не читались.
- **Календарь пересчитывает дни рождения на выбранный год** через
  `occurrencesInYear`. Список из репозитория содержит ближайшее
  вхождение от «сегодня», поэтому для произвольных годов оно не годится.
- **Уведомления одного дня объединяются**: `groupByFireAt` и `textFor`.
  Без этого Android показывал бы только последнее из нескольких.
- **AMOLED — четыре ступени поверхностей**, закреплены тестами на
  строгий порядок яркости. На AMOLED нельзя заливать панели
  полупрозрачным цветом: чёрный плюс alpha 0.3 даёт тот же чёрный.
- **Круг дня рождения рисуется через `Path` с `arcTo`**, а не через
  `drawArc`: дуга по меньшему радиусу давала овал. Размер задаёт
  вызывающий код явно, потому что `CustomPaint` в `Stack` без `SizedBox`
  растягивается и схлопывается.
- **Импорт заменяет список**, а не дополняет — иначе получился бы
  дубль из двух списков.
- **Поиск в Dart, не в SQL**: `lower()` в SQLite не понимает кириллицу.
- **`stableNotificationId` — FNV-1a вручную**: встроенный `hash()`
  нестабилен между запусками.
- **Индексы вкладок связаны по `id`**, не по позиции.

## Что не сделано

- Синхронизации между устройствами нет.
- MSIX-упаковки для Windows нет, поэтому `cancelAll` и `pending()`
  там не работают — это ограничение плагина, не наш баг.
- Несколько профилей в UI нет (модель и провайдер есть).
- Виджетов на рабочем столе нет.

## Известные грабли

- **PowerShell добавляет BOM** в `Set-Content -Encoding UTF8`, и
  Dart-паркер после этого падает. Правь Dart-файлы через `apply_patch`; если
  писал скриптом — убирай BOM вручную.
- **PowerShell читает `.ps1` в однобайтовой кодировке** и ломается на
  кириллице. Скрипты публикации — латиницей, текст в отдельном
  UTF-8 файле.
- **`git credential fill` не работает через пайплайн PowerShell** —
  stdin обрезается. Рабочий путь: `git-credential-manager get` с файлом
  запроса.
- **Gradle качает 18 версий дистрибутива** в
  `caches/gradle/wrapper/dists` (~5 ГиБ), проект использует одну.
  Лишнее можно удалять.
- **`C:\Users\Admin\.gradle`** — 2.1 ГиБ кэша от 29 сентября, к проекту
  отношения не имеет.
- **Эмулятор сворачивает приложение**, если тап промахнулся мимо элемента,
  и системный диалог выбора файла иногда зависает поверх. Лечится
  `am force-stop` и повторным запуском.
